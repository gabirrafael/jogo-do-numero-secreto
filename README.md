## 📖 Sobre o Projeto

Este é um jogo interativo de lógica onde o jogador precisa adivinhar um número secreto entre 1 e 100. O projeto conta com feedback visual e auditivo para guiar o usuário até a resposta correta, informando se o chute deve ser maior ou menor. 

## ✨ Funcionalidades

- Sorteio dinâmico de um número.
- Validação de tentativas.
- Contagem do número de tentativas até o acerto.
- Feedback de voz em português utilizando a API `ResponsiveVoice`.
- Bloqueio e desbloqueio dinâmico do botão de "Novo jogo".

## 🧠 Desafios e Evolução

Neste repositório, além do jogo principal, decidi manter os arquivos de atividades propostas ao longo do curso para registrar a minha evolução lógica e o desenvolvimento do pensamento computacional:

- **`01desafio.js`**: Criação de funções básicas, passagem de parâmetros e retornos simples (ex: cálculos matemáticos e saudações).
- **`02.desafio.js`**: Aplicação de lógicas matemáticas mais elaboradas, utilizando `while`, cálculo de IMC, fatorial, conversão cambial (dólar para real) e cálculos geométricos (área e perímetro).
- **`03desafio.js`**: Fundamentos de manipulação de listas (Arrays), utilizando métodos como `.push()` e acessando elementos por seus índices.
